## Synchronisation automatique

`sync-forks.yml` fusionne chaque jour l'amont dans les forks, via l'endpoint `merge-upstream`. Il faut un secret `SYNC_TOKEN` : PAT fine-grained couvrant les dépôts listés, `Contents: Read and write`.

Sans ce secret, le workflow échoue explicitement au lieu de ne rien faire.
